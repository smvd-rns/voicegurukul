👑 Royal Camp Registration & Role Assignment Workflow

Exclusive Leadership Camp — Access Restriction
The Royal Camp is an exclusive leadership retreat track that is completely hidden from the camp dropdown for regular users. Only devotees who hold a recognized leadership role or Royal Member status can see and register for this camp.
⚠️
Important Instruction: Kindly do not enroll frontliners.
The Royal Camp is strictly reserved for qualifying leadership roles and mentors only. Frontliners are not eligible.

Complete List of Qualifying Royal Camp Roles:

OC (Overall Coordinator) Care Giver Youth Preacher Internal Manager Preaching Coordinator Director Managing Director Acting Manager Project Manager Central VOICE Manager Project Advisor Voice Manager Mentors (Chanting minimum 16 rounds at least for 6 months and taking responsibility for boys)
Step-by-Step How Managers Assign Royal Roles to Devotees
  1. Devotee Registers on Website First: Devotee creates a basic user account on voicegurukul.com.
  2. Manager Opens Project Manager Section: Go to Project Manager → Total Devotees (If section not visible, call Sri Murali Vadan Das at +91 7387876169).
  3. Assign Role / Royal Member: Locate devotee, click Edit Profile, assign any qualifying role above (e.g. Director, OC, Youth Preacher, Internal Manager, Care Giver) and update.
  4. Register for Camp: Open Camps → Register, select that devotee → Royal Camp will now appear in the dropdown!
📷 Screen: Assigning Roles / Royal Member Status in Project Manager → Total Devotees Section
Need Assistance with Role Setup?
If a devotee's role is not activating or the Project Manager section is unavailable, please reach out to the Central Coordinator.
